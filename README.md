# Canno

Canno is a spreadsheet program.

C++ Core Engine + GUI in either Python or C++ Qt.

## Features
- [X] `Formulas`
    - [X] `Cell references`
    - [X] `Binary operations`
    - [X] `Functions`
    - [ ] `Parentheses`
- [X] `Graph dependency tree`
- [X] `Frontend updates only updates changed cells`
- [X] `Error handling`
- [X] `Circular dependency detection`
- [X] `Ranges =SUM(A1:A5)`
- [X] `Saving & loading from file`
